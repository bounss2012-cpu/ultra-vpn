## 🚀 Utilisation Rapide

### Pour les Débutants

```
1. Ouvrez Roblox Studio
2. Créez un LocalScript dans StarterPlayer > StarterCharacterScripts
3. Copiez le code de KnifePickupSimple.lua
4. Créez un Tool "Knife" avec un Handle dans le Workspace
5. Appuyez sur Play et testez avec la touche E
```

### Pour un Résultat Professionnel

```
1. Ouvrez Roblox Studio
2. Créez un Script dans ServerScriptService
3. Copiez le code de KnifePickupProximityPrompt.lua
4. Créez un Tool "Knife" avec un Handle
5. Profitez de l'interface moderne!
```

## 🔧 Personnalisation

Tous les scripts sont facilement personnalisables:

```lua
-- Changer la touche
local PICKUP_KEY = Enum.KeyCode.E  -- Changez E par F, Q, R, etc.

-- Changer la distance
local MAX_PICKUP_DISTANCE = 10  -- En studs

-- Changer le nom
local KNIFE_NAME = "Knife"  -- Ou "Sword", "Dagger", etc.
```
